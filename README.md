# Moon Onyx Labs MVP v2.1 — Day 1 Polish

A one-platform, three-tool MVP for Moon Onyx Labs.

## Tools Included

1. Executive Clarity Analyzer
2. KPI Cleaner
3. Insight Generator Lite

## Day 1 Upgrades Added

- Copy input button
- Copy full output button
- Copy buttons on result sections
- Futuristic loading animation
- Stronger empty states
- Sample input button for each tool
- Better feedback for copied output
- Sharper grid-style background

## Run Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

## Run Frontend

Open a second terminal:

```bash
cd frontend
npm install
npm run dev
```
